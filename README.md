# jShamsul.com

The source for J. Shamsul’s personal website and blog. It brings together essays, the Code & Codex archive, a bookshelf, and ways to connect with J. Shamsul (@jibone).

The Next.js application lives in [`web/`](web/). See [`web/README.md`](web/README.md) for setup, routes, and content authoring.

## Run locally

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
